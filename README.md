# 工程報價單（trade-quote）

給水電／冷氣／油漆師傅在現場用手機快速開立報價單的單檔網頁工具。

## 使用方式
直接用瀏覽器打開 `index.html` 即可（手機、電腦皆可），不需安裝或後端。
建議放到 GitHub Pages 等靜態空間，手機用網址開啟後「加入主畫面」。

## 功能
- 首頁儀表板：本月報價、待簽約、待收款、本月成交；列表可搜尋、依狀態篩選
- 三步驟開單：客戶資料 → 點選常用工料（只需輸入數量）→ 付款比例／保固／工期／條款
- 自動流水號（QUO-YYYYMMDD-001）、日期、小計／總額、三期請款金額、國字大寫金額
- 含料／純工資標記、優惠折讓、5% 營業稅選項
- A4 報價單預覽，匯出高畫質圖片、PDF（自動分頁）、一鍵 LINE 分享
- 常用工料庫自訂、公司資訊／Logo／匯款帳號自動帶入
- 資料存在瀏覽器 localStorage，可匯出／匯入 JSON 備份

圖片／PDF 匯出需連網載入 html2canvas、jsPDF（cdnjs）；離線時會改用瀏覽器列印。
